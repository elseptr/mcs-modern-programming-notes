# 🎓 Обитель мудрости страдающих студентов СП МКН (2026–2030?)

## Правила добавления материалов

Пожалуйста, придерживайтесь следующих простых правил при добавлении новых материалов в репозиторий.

1. **Сохраняйте общую структуру.**  
   Все материалы размещаются в папке соответствующего года и предмета. Старайтесь придерживаться уже существующей организации репозитория.

2. **Создание папки предмета.**  
   Если нужного предмета ещё нет, создайте для него папку непосредственно в папке соответствующего года. Используйте понятное и общепринятое название предмета. Перед созданием убедитесь, что такой предмет ещё не представлен в репозитории.

3. **Организуйте материалы по смыслу.**  
   Внутри папки предмета можно создавать дополнительные папки для разделения материалов по темам, блокам, лекциям, практикам и другим категориям. Главное, чтобы из названий папок было понятно, какие материалы в них находятся. Не создавайте избыточную вложенность.

4. **Называйте файлы понятно.**  
   Используйте название темы или дату занятия в формате `DD-MM-YYYY`. Если необходимо, добавляйте краткое уточнение, например `25-11-2026 - Seminar.pdf`. Избегайте названий вроде `new`, `final2`, `notes1`.

5. **Не дублируйте материалы без необходимости.**  
   Перед добавлением проверьте, нет ли уже такого конспекта или файла. Если материал дополняет существующий, по возможности размещайте его рядом с соответствующими материалами.

6. **Бережно относитесь к существующей структуре.**  
   Не переименовывайте, не перемещайте и не удаляйте чужие материалы без необходимости. При добавлении своих файлов старайтесь не нарушать уже сложившуюся организацию.

---

*Главная цель — поддерживать понятную и удобную структуру репозитория, чтобы каждый мог легко найти нужные материалы.*
